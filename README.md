# Sourcegrove

Sourcegrove is being rebuilt in TypeScript on Bun canary.

[Synthesis](https://github.com/the-strategy-unit/synthesis) is Sourcegrove's
predecessor. Its Go implementation provides the functional reference for this
rewrite.

This repository is a fresh starting point. Application implementation has not
started.
